📋 mcp-reportcard

A health check for MCP servers. Paste a server's tools/list JSON and get a graded report card for its tool names, descriptions, schemas, safety annotations and token cost, with a concrete fix for every issue. The checker runs entirely in your browser (Python via Pyodide), so nothing you paste leaves this page.

Loading Python in your browser…

Get the JSON from your own server with the CLI: mcp-reportcard dump "python server.py". The CLI can also fuzz a live server's error handling — see GitHub.

mcp-reportcard is open source (MIT). Built by Gopi K Aitham (builditwithgk) · scaleup-solutions.in. Token counts here use a characters/4 estimate; the CLI with [tokens] uses tiktoken.
