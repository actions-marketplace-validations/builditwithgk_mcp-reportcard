MCP Doctor

A health check for MCP servers. Paste a server's tools/list JSON and get a graded report card for its tool names, descriptions, schemas, safety annotations and token cost, with a concrete fix for every issue. Nothing you paste is stored or sent anywhere.

Load a bad example Load a good example

Get the JSON from your own server with pip install mcp-doctor then mcp-doctor dump "python server.py". The CLI can also fuzz a live server's error handling.
